# «Зал клинков» — структура игры

Небольшая браузерная игра на TypeScript + Phaser. Внутреннее разрешение — **480×270**.
База — зал рыцарского замка: каменные стены, витражи, гербы, ковёр, жаровни и торговец.

## Игровой цикл

1. В зале отдохните у центральной жаровни и купите снаряжение у торговца внизу.
2. Нажмите **I**, выберите купленный предмет и нажмите Enter / клик, чтобы экипировать его.
3. Северные ворота открывают выбор арены: **Турнирный двор → Забытый склеп → Багровая кузня**.
4. Победите конечные волны, затем Короля слизней и его призванных помощников. Откроется следующая арена.
5. Монеты за каждого врага и награда за прохождение сразу сохраняются в кошельке. Повторные прохождения тоже дают монеты.
6. Вернитесь через ворота внизу арены, удерживая E. Можно уйти до победы, но следующий уровень не откроется.

За монеты продаются меч (+2 урона), кольчуга (+20 максимального здоровья), сумка (+12 мест) и эликсиры.
Снаряжение покупается один раз, эликсиров можно носить до пяти. Предметы остаются в инвентаре после снятия.
Кольчуга не лечит при экипировке; восстановите здоровье у жаровни. Нельзя снять полную сумку.

Сбор ресурсов и улучшения базы сохранены: разбивайте ящики, камни и мешки с припасами.
Оружейная, покои, казначейство и аптекарский стол улучшаются за материалы.
При возвращении ресурсы переезжают на склад; при поражении теряется половина каждого вида ресурсов из рюкзака.
**Монеты и купленные предметы не теряются.**

## Файлы

- `configs/items.ts` — цены и бонусы предметов, награды, состав волн, уровни, улучшения базы.
- `configs/settings.ts` — параметры боя, движения, рюкзака и лечения.
- `state/Session.ts` — кошелёк, инвентарь, экипировка, прогресс и localStorage.
- `scenes/BaseScene.ts` — зал замка, торговец, улучшения, выбор арены.
- `scenes/ExpeditionScene.ts` — общая сцена трёх арен с разной палитрой и сложностью.
- `scenes/UIScene.ts` — HUD, магазин, инвентарь, окна выбора и пауза.
- `systems/CastleArt.ts` — новые пиксельные объекты и каменные карты, рисуемые Canvas один раз при загрузке.
- `systems/EnemyManager.ts`, `characters/` — существующие мобы и бой.
- `systems/Nodes.ts`, `systems/Loot.ts` — разрушаемые припасы и добыча.

Старые сохранения «Лагеря у Чащи» читаются с тем же ключом. Ресурсы и улучшения сохраняются,
а победа над старым боссом открывает второй уровень. Новые поля дополняются значениями по умолчанию.
Спрайты героя и врагов сохранены; новых зависимостей, сервера и сетевой игры нет.

## Управление

WASD / стрелки — ходьба; ПРОБЕЛ / J / ЛКМ — удар; SHIFT / K — рывок;
E / Enter — действие; **I — инвентарь**; Q — эликсир на арене;
Esc / P — пауза; M — звук; F — полный экран.

## Проверка

```bash
npm run typecheck
npm run build
npm run dev
```

Ручной сценарий: новая игра → торговец → купить меч за стартовые 30 монет → I → экипировать
(урон 2 → 4) → северные ворота → пройти первую арену → вернуться → проверить кошелёк
и открытый склеп → перезагрузить страницу → «Продолжить».
Отдельно проверьте поражение, ранний выход с арены, повторную покупку уже имеющегося предмета и лимит эликсиров.

Ограничения: три арены используют существующие типы монстров и одного босса с разным запасом здоровья;
баланс требует игрового тестирования. Сохранение локальное, только в текущем браузере.
