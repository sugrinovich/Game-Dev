# Структура текущей игры

Игра показывает игрока и мобов на однотонном фоне во всё окно браузера.
Камера неподвижна. Размер поля меняется вместе с окном.

- `config.ts` — настройки Phaser и масштабирования.
- `scenes/BootScene.ts` — загрузка четырёх листов спрайтов и создание анимаций.
- `scenes/GameScene.ts` — запуск, обновление, пауза и полноэкранный режим.
- `characters/Player.ts` — движение и анимации игрока.
- `characters/Mob.ts` — общие размер и скорость мобов.
- `characters/Slime.ts` — преследование по четырём направлениям, анимации и тень.
- `systems/EnemyManager.ts` — появление и расталкивание мобов.
- `configs/game.ts` — параметры экрана, сцены и слои.
- `configs/settings.ts` — скорость, размеры, число и частота появления мобов.
- `configs/characters.ts` — конфигурации персонажей.
- `configs/assets.ts` — ключи спрайтов, кадры и анимации.
- `types.ts` — тип координат.

Ресурсы находятся в `src/assets/characters/`. Неиспользуемые модули карты,
интерфейса, монет и оружия, их ресурсы и параметры удалены.

## Управление

- WASD / стрелки — движение.
- F — вход и выход из полноэкранного режима браузера.
- Esc / P — пауза и продолжение.
- R — перезапуск.

При потере фокуса включается пауза; для продолжения нажмите Esc или P.
На очень маленьком окне мобы могут тесниться: их размер и количество не уменьшаются.

## Проверка

Выполните `npm run typecheck` и `npm run build`.
Для ручной проверки запустите `npm run dev`: проверьте движение, появление мобов,
изменение размера окна, F, паузу и несколько перезапусков через R.

Все зависимости используются: Phaser — движок, TypeScript — проверка типов,
Vite — сервер разработки и сборка. TypeScript strict включён.
