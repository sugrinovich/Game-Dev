# «Лагерь у Чащи» — структура игры

Пиксельная игра: лагерь, который растёт и улучшается, и вылазки в локации с мобами и ресурсами.
Внутреннее разрешение — **480×270**, окно масштабируется целым числом раз (пиксели ровные).

## Игровой цикл

1. `PreloadScene` — экран загрузки с названием и полосой прогресса.
2. `MenuScene` — «Начать игру / Продолжить / Выйти».
3. `BaseScene` — лагерь: костёр (отдых + сохранение), 4 места под постройки, ворота на вылазку.
4. `ExpeditionScene` — локация 1 «Мшистая Лощина»: ресурсы, мобы, Король слизней, обелиск возврата.
5. Добыча из рюкзака переезжает на склад при возврате; при гибели теряется половина.

## Файлы

- `config.ts` — настройки Phaser, список сцен, целочисленный масштаб.
- `scenes/` — `BootScene` (шрифты), `PreloadScene`, `MenuScene`, `WorldScene` (общая база лагеря и вылазки),
  `BaseScene`, `ExpeditionScene`, `UIScene` (HUD, окна выбора, пауза).
- `characters/` — `Player`, `Mob` (общее), `Slime`, `Sporeling`, `Wasp`, `SlimeKing`.
- `systems/` — `EnemyManager`, `Terrain` (рисование земли и воды), `Colliders` (столкновения),
  `Nodes` (деревья/камни/кусты, которые бьют дубиной), `Loot`, `Effects` (частицы), `Sfx` (звук и музыка без файлов).
- `state/Session.ts` — сохранение (localStorage), рюкзак, параметры героя от построек.
- `ui/` — `PText` (текст пиксельным шрифтом), `Panel` (рамки).
- `configs/` — `game.ts`, `settings.ts`, `assets.ts`, `characters.ts`, `items.ts` (ресурсы, постройки, локации).
- `types.ts` — `Point` и интерфейс `Arena`.

Ресурсы: `src/assets/characters/` — ваши спрайты (не менялись), остальное рисуется скриптами из `tools/`
(атлас `sprites.png/json`, шрифты `fonts/`, фоны `title/`).

## Управление

- WASD / стрелки — ходьба (по диагонали тоже), ПРОБЕЛ / J / ЛКМ — удар, SHIFT / K — рывок,
  E / Enter — действие (удерживать у обелиска), Q — припарка, Esc / P — пауза, M — звук, F — полный экран.

## Как расширять

- **Новая постройка:** добавьте запись в `BUILDINGS` (`configs/items.ts`), кадры `имя_1..3` в `tools/gen_base.py`,
  эффект — в `Session` (геттеры вроде `maxHp`).
- **Новый моб:** запись в `ENEMY_TYPES` (`configs/characters.ts`), класс наследует `Mob`, добавьте в `MOB_CLASSES`
  (`systems/EnemyManager.ts`).
- **Новая локация:** запись в `LOCATIONS` (`playable: true`), тему цветов — в `THEMES` (`systems/Terrain.ts`),
  сцену по образцу `ExpeditionScene`. Каменные пещеры и Туманное болото уже показаны в списке как закрытые.
- **Новые картинки:** правьте `tools/gen_*.py` и запустите `npm run assets` (нужен Python 3 + Pillow).

## Проверка

`npm run typecheck`, `npm run build`, затем `npm run dev` и пройдите цикл:
меню → лагерь → ворота → вылазка (бить деревья, камни, мобов) → обелиск → постройка → Король слизней.
