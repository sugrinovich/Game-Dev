# «Осада Бездны» — структура игры

Небольшая браузерная игра на TypeScript + Phaser. Внутреннее разрешение — **480×270**.
**Файлов картинок и шрифтов нет**: вся графика, шрифт и иконки рисуются кодом на экране загрузки.
База — зал рыцарского замка: каменные стены, витражи, гербы, ковёр, жаровни и торговец.

## Игровой цикл

1. В зале отдохните у центральной жаровни и купите снаряжение у торговца внизу.
2. Нажмите **I**, выберите купленный предмет и нажмите Enter / клик, чтобы экипировать его.
3. Северные ворота открывают выбор арены: **Турнирный двор → Забытый склеп → Багровая кузня**.
4. Победите волны орды (скелеты-мечники и лучники, орки, со второй арены — огры), затем Короля Бездны:
   он мечет огненные шары в точку под героем и призывает скелетов. Откроется следующая арена.
5. Монеты за каждого врага и награда за прохождение сразу сохраняются в кошельке. Повторные прохождения тоже дают монеты.
6. Вернитесь через ворота внизу арены, удерживая E. Можно уйти до победы, но следующий уровень не откроется.

За монеты продаются меч (+2 урона), кольчуга (+20 максимального здоровья), кошель охотника (+3 монеты за врага) и эликсиры.
Снаряжение покупается один раз, эликсиров можно носить до пяти. Предметы остаются в инвентаре после снятия.
Кольчуга не лечит при экипировке; восстановите здоровье у жаровни.

Единственная валюта — **монеты**. Оружейная, покои, казначейство и аптекарский стол улучшаются за монеты.
Казначейство добавляет монеты за каждого врага, аптекарский стол после вылазок выращивает эликсиры,
в оружейной можно сварить эликсир дешевле, чем у торговца.
**Монеты и купленные предметы не теряются.**

## Файлы

- `configs/items.ts` — цены и бонусы предметов, награды, состав волн, уровни, улучшения базы.
- `configs/settings.ts` — параметры боя, движения, лечения и размер крупных объектов (`props.maxHeight`).
- `state/Session.ts` — кошелёк, инвентарь, экипировка, прогресс и localStorage.
- `scenes/BaseScene.ts` — зал замка, торговец, улучшения, выбор арены.
- `scenes/ExpeditionScene.ts` — общая сцена трёх арен с разной палитрой и сложностью.
- `scenes/UIScene.ts` — HUD, магазин, инвентарь, окна выбора и пауза.
- `systems/CastleArt.ts` — пиксельные объекты и каменные карты, рисуемые Canvas один раз при загрузке.
  Анимированные объекты (жаровни, знамёна, портал, торговец, постройки) — листы кадров через `sheet()`;
  `addCastleAmbience()` добавляет мерцающие лучи из витражей и пылинки.
  Стоящие объекты рисуются в виде сверху-спереди (3/4) из примитивов `block` (скруглённый брус с верхней гранью),
  `cylinder` (цилиндр с крышкой-эллипсом), выпуклых форм из `Volume.ts` и `ellipse`; плоский — только пол.
  Стены объёмные (`WALL`): кладка из выпуклых камней, видимая сверху толщина стены, круглый цоколь, окна в нишах,
  круглые башни по углам. Ближняя стена с ближними башнями — отдельный слой поверх героя (`addCastleFront`):
  у нижней стены герой заходит за кладку; на аренах в ней проём для ворот.
- `systems/TitleArt.ts` — заставка «Осада Бездны» для загрузки и меню: замок, рыцарь, орда (орки, огры, скелеты),
  Короли Бездны мечут огненные шары. Расстановка и ритм — константа `SIEGE`.
- `systems/Volume.ts` — объём для нарисованных кодом спрайтов: свет сверху-слева (блик и тень по краю силуэта,
  градиент по высоте), скругление углов силуэта. Сила эффектов — в `VOLUME`, `ROUNDING`.
  Здесь же примитивы объёмных форм со светотенью по нормали: `blob` (овал / скруглённый брусок), `tube` и `htube`
  (цилиндр стоя и лёжа), `cone` (мантия), `slab` (скруглённый брус 3/4); тона материала — `ramp()`, `tone()`.
- `systems/HeroArt.ts` — герой-«кукла»: базовое тело считает точки крепления (голова, торс, бёдра, ноги, руки, кисть),
  вещи из `GEAR` цепляются к ним по слотам (`legs`, `feet`, `body`, `belt`, `head`, `weapon`). Стартовая одежда —
  шорты и палка (`STARTER_OUTFIT`). Новая вещь: запись в `GEAR` + поле `wear` у предмета в `SHOP_ITEMS`.
  Тела (`BODIES`): `human`, `skeleton`, `orc`, `ogre`, `abyssKing`; у каждого своё телосложение (`Build`: кадр,
  размеры головы, торса, рук и ног). Объём — примитивы из `Volume.ts`.
- `systems/EnemyManager.ts`, `characters/` — враги и бой:
  - `Skeleton.ts` — скелет-мечник (замах и удар) и скелет-лучник (держит дистанцию, стреляет; стрелы упираются
    в препятствия);
  - `Brute.ts` — орк-рубака (быстрый удар топором) и огр-громила (удар дубиной по площади с кругом-предупреждением);
  - `AbyssKing.ts` — босс: огненные шары из сферы над ладонью в точку под героем, призыв скелетов на 2/3 и 1/3 здоровья;
  - все враги — куклы из HeroArt: тело и вещи задаются в `ENEMY_TYPES` (`configs/characters.ts`), поворот и шаг
    в 8 сторон — в `Mob.ts`.
- `systems/MobArt.ts` — огненный шар Короля Бездны и эффекты ударов.
- `systems/IconArt.ts` — объёмные иконки и герб: приём «выпуклой подушки» `emboss` (высота от края к середине,
  свет сверху-слева) и палитры материалов `MATERIAL` (золото, сталь, рубин, стекло, кожа…).
- `systems/MapBounds.ts` — стены карты; препятствия внутри — круги в `systems/Colliders.ts`.
- `ui/PixelFont.ts` — собственный шрифт: пиксельные капители (`ui`) и заголовочный «широким пером» (`big`);
  объём (градиент, контур, выдавленная грань) запечён в буквах.
- `ui/Panel.ts` — рыцарский интерфейс: окна (`drawPanel`), алые ленты (`drawRibbon`), полоски с ромбами (`drawBar`),
  плашки (`drawPlate`).

Сохранение — в localStorage браузера под ключом `abyss-siege/save-v1`.
Внешних зависимостей, кроме Phaser, нет; сервера и сетевой игры нет.

## Управление

WASD / стрелки — ходьба; ПРОБЕЛ / J / ЛКМ — удар; SHIFT / K — рывок;
E / Enter — действие; **I — инвентарь**; Q — эликсир на арене;
Esc / P — пауза; M — звук; F — полный экран; ` (Ё) — счётчик FPS.

## Плавность (60 FPS)

- Все текстуры рисуются кодом на экране загрузки по заданиям: не дольше `JOB_BUDGET_MS` за кадр
  (`scenes/PreloadScene.ts`), большие листы — по 8 кадров за задание (`sheetJobs` в `CastleArt.ts`).
  Заранее готовятся пол зала и всех арен, все сочетания снаряжения героя, орда (скелеты, орки, огры, Король) и стрела —
  во время игры ничего тяжёлого не рисуется.
- Частицы берутся из пула (`Effects.ts`), а не создаются заново — меньше работы сборщику мусора.
- Камера плавно догоняет героя (`CAMERA_SMOOTH` в `WorldScene.ts`), спрайты и карта стоят на целых пикселях
  (`roundPixels`), а увеличение окна подбирается так, чтобы на игровой пиксель приходилось целое число
  физических пикселей экрана (`pickZoom` в `config.ts`, учитывает масштаб Windows/macOS) — карта не дрожит.
- Герой и все враги ходят в 8 сторон (диагонали — вполоборота); при повороте шаг не сбивается (`playKeepingStep`),
  на границе секторов направление не мигает (`facingOf`).
  Оружие всегда в правой руке: правые стороны рисуются зеркалом, но рука с оружием выбирается до отражения
  (`gripSide`, `gripFar` в `buildRig`); при взгляде влево оружие в дальней руке — перед грудью, за телом.
- Счётчик FPS в игре — клавиша ` (Ё): зелёный — 58+ кадров, красный — просадка.

## Проверка

```bash
npm run typecheck
npm run build
npm run dev
```

Ручной сценарий: новая игра → торговец → купить меч за стартовые 30 монет → I → экипировать
(урон 2 → 4) → северные ворота → пройти первую арену → вернуться → проверить кошелёк
и открытый склеп → перезагрузить страницу → «Продолжить».
Отдельно проверьте поражение, ранний выход с арены, повторную покупку уже имеющегося предмета и лимит эликсиров.

Ограничения: три арены используют существующие типы монстров и одного босса с разным запасом здоровья;
баланс требует игрового тестирования. Сохранение локальное, только в текущем браузере.
