# Последний рыцарь: Осада Бездны

Браузерная игра для курса **«Проектирование и разработка игровых приложений»**.
Стек: **TypeScript + Phaser + Vite + GitHub Pages**.

**Играть:** https://sugrinovich.github.io/Game-Dev/

## Об игре

Вы — последний рыцарь замка, который осаждает Бездна. Из тронного зала через чёрный разлом вы уходите на арену —
круглый колизей, где этаж за этажом приходят волны врагов, а каждый 10-й этаж — Король Бездны. Монеты за врагов
тратятся в замке у торговца на оружие, доспехи и магию; всё, что лежит в сумке, работает в бою.

**Игровой цикл одним предложением:** рыцарь уклоняется и рубит врагов, чтобы пройти как можно больше этажей
и заработать монеты, пока волны растут и меняются, после чего в замке он покупает снаряжение и пробует побить рекорд.

**Цель вылазки** — пройти больше этажей, чем в прошлый раз (рекорд виден на арене сверху). Поражение не отнимает
монеты и вещи: героя приносят в замок, можно сразу пробовать снова.

**Как меняется вылазка** (план прогрессии, `ARENA_PHASES` в `src/game/configs/items.ts`):

| Этаж | Что меняется |
|---|---|
| 1–2 | только скелеты-мечники |
| 3 | орки — быстрее |
| 4–5 | скелеты-лучники — угроза издалека |
| 6 | разломы в полу замедляют героя (их можно разбить) |
| 7–9 | все угрозы вместе |
| 10 | Король Бездны, затем передышка и выбор одного из трёх усилений на остаток вылазки |
| 11+ | огры-громилы с ударом по кругу; каждый 10-й этаж — снова Король и выбор |

## Управление

Игра пока **только для компьютера с клавиатурой** (на телефоне управления нет).

| Клавиша | Действие |
|---|---|
| W A S D | ходьба |
| ПРОБЕЛ | удар туда, куда смотрит герой |
| SHIFT | рывок |
| E | действие (у предметов и в окнах — выбрать) |
| Q | эликсир |
| TAB | инвентарь |
| P | меню (пауза) |
| M / F | звук / полный экран |

## 1. Что нужно установить

- **Node.js 22 LTS** (или Node.js >= 20.19)
- **Git**
- **VS Code** или другая IDE
- аккаунт **GitHub**

Проверка:

```bash
node --version
npm --version
git --version
```

## 2. Первый запуск

```bash
npm install
npm run dev
```

Vite напечатает адрес локального сервера. Обычно это:

```text
http://localhost:5173/
```

Открой его в браузере.

## 3. Где менять баланс

Главные числа игры собраны в конфигах `src/game/configs/`:

- `items.ts` — этажи арены (`ARENA_FLOORS`), план прогрессии (`ARENA_PHASES`), усиления после Короля (`RUN_BOONS`),
  разломы в полу (`FLOOR_RIFT`), монеты (`ECONOMY`), предметы и цены;
- `characters.ts` — враги: скорость, здоровье, урон;
- `settings.ts` — герой и бой: скорость, удар, рывок, неуязвимость.

Меняйте 1–2 числа за раз, играйте полную вылазку и сравнивайте (лекция 7).

## 4. Проверка production build

Перед публикацией:

```bash
npm run build
```

Если команда завершилась без ошибок, итоговая версия находится в папке `dist/`.

Её можно проверить локально:

```bash
npm run preview
```

## 5. Публикация на GitHub Pages

В репозитории уже есть workflow:

```text
.github/workflows/deploy.yml
```

После push в ветку `main` GitHub автоматически собирает проект.

Для первого включения Pages:

1. открой репозиторий на GitHub;
2. **Settings → Pages**;
3. в **Build and deployment → Source** выбери **GitHub Actions**;
4. открой вкладку **Actions** и дождись успешного `Deploy to GitHub Pages`;
5. ссылка на игру появится в deployment и в разделе Pages.
