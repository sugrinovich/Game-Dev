# Скрипты рисования

Весь новый пиксель-арт нарисован кодом (Python + Pillow) в одном стиле с вашими спрайтами:
свет сверху-слева, тёмно-фиолетовый контур, тёплые коричневые и приглушённая зелень.

```bash
pip install pillow
python3 tools/make_assets.py     # или: npm run assets
```

- `pxlib.py` — мини-библиотека рисования (маски, объёмная заливка, контур).
- `gen_props.py` — деревья, камни, кусты, грибы, цветы.
- `gen_base.py` — костёр, факелы, ворота, обелиск, здания (3 уровня), огород.
- `gen_mobs.py` — споровик, шершень, корона, эффекты, иконки.
- `gen_title.py` — слои титульного экрана.
- `gen_fonts.py` — растровые шрифты с кириллицей (нужны DejaVu Sans Mono и GNU Unifont; пути для Linux).

Готовые PNG уже лежат в `src/assets/` — запускать скрипты нужно только чтобы что-то перерисовать.
